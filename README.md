Projeto desenvolvido durante a **Imersão Python com Dados II da Alura**, 
com foco na construção de uma aplicação interativa para exploração, análise 
e visualização de dados.
A solução utiliza **Python, Pandas, Streamlit e Plotly** para transformar dados 
estruturados em uma experiência analítica acessível pelo navegador, combinando 
tratamento de dados, indicadores, filtros e visualizações interativas.

----

## 🎯 Objetivo

Construir uma aplicação de Data Analytics capaz de transformar um conjunto de 
dados em informações visualmente acessíveis e exploráveis pelo usuário.

O projeto aplica conceitos relacionados a :

- Análise de dados com Python
- Manipulação de DataFrames
- Preparação de dados
- Criação de KPIs
- Visualização interativa
- Construção de dashboards
- Desenvolvimento de Data Apps
- UX aplicada à análise de dados

---

## 📊 Dashboard

A aplicação foi desenvolvida com **Streamlit**, permitindo transformar análises 
realizadas em Python em uma interface web interativa.
O dashboard combina processamento de dados e visualização para facilitar a 
exploração das informações diretamente pelo navegador.

---

## 📈 Visualização de Dados

O **Plotly** é utilizado para criação de visualizações interativas, permitindo 
representar os dados de maneira mais dinâmica do que gráficos estáticos tradicionais.

A combinação entre Streamlit e Plotly permite integrar:

**Dados + Indicadores + Filtros + Visualização + Interatividade**

em uma única aplicação.

## ▶️ Executando Localmente

Clone o repositório:

git clone https://github.com/MCLG1661/Alura-Imersao-Dados-Python-II.git

Entre no diretório:

```bash
cd Alura-Imersao-Dados-Python-II

```

Instale as dependências:

```bash
pip install -r requirements.txt

```

Execute a aplicação:

streamlit run App.py

O Streamlit abrirá a aplicação no navegador.
